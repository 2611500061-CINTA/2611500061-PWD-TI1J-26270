# Pertemuan 4 - CSS3 Layout dan Responsive Web Design

## Pengembangan
- Perubahan yang dilakukan: Menerapkan Flexbox pada navigasi dengan `display: flex`, `flex-direction: column`, `justify-content`, `align-items`, dan `gap`. Menambahkan `margin`, `padding`, dan `list-style: none` untuk mengatur tampilan daftar navigasi serta mengatur tampilan link navigasi menggunakan `nav a`.
- Commit dan push GitHub: Perubahan telah disimpan, dilakukan commit, dan berhasil di-push ke repository GitHub.

## Pengujian
- Perangkat bergerak: Viewport 375 × 667 px. Navigasi tersusun secara vertikal dan halaman dapat ditampilkan dengan baik.
- Desktop: Viewport 1366 × 768 px. Navigasi tersusun secara vertikal dan halaman dapat ditampilkan dengan baik.
- Galat dan perbaikan: Tidak terdapat galat setelah dilakukan perbaikan pada aturan CSS navigasi.
- Validasi CSS: CSS telah divalidasi dan tidak terdapat galat. Perbaikan dilakukan pada aturan Flexbox dan navigasi agar sesuai dengan ketentuan.
