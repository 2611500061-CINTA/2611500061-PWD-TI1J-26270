# pertemuan-08

1. Saya menyalin folder bahan Pertemuan 07 ke folder pertemuan-08.

2. Saya menambahkan menu navigasi baru bernama **Peminjaman Fasilitas**. Menu ini mengarah ke section formulir peminjaman yang baru.

3. Saya membuat section **Permohonan Peminjaman Fasilitas Kampus** sebelum section Kontak. Formulir berisi nama penanggung jawab, jenis fasilitas, tanggal peminjaman, durasi peminjaman, dan keperluan peminjaman.

4. Saya menambahkan pilihan fasilitas berupa Ruang Kelas, Aula, Laboratorium Komputer, dan Proyektor. Saya juga menambahkan tombol **Kirim** dan **Batal**.

5. Saya membuat pemrosesan formulir peminjaman menggunakan metode POST dan PHP. Data yang berhasil diproses ditampilkan kembali di section peminjaman.

6. Saya menambahkan validasi JavaScript dan PHP, normalisasi masukan menggunakan `trim()`, serta sanitasi tampilan menggunakan `htmlspecialchars()`.

7. Saya menggunakan session dan pola Post-Redirect-Get (PRG) supaya formulir tidak terkirim ulang saat halaman dimuat kembali.

8. Saya memisahkan pemrosesan formulir peminjaman dari formulir Kontak supaya fitur Kontak tetap berjalan.

9. Saya menguji menu, formulir, validasi, pengiriman data, dan tampilan data. Saya juga memastikan tombol Batal berfungsi serta fitur Kontak dan fitur aplikasi sebelumnya tetap bisa digunakan.

10. Setelah selesai, saya menambahkan dan menyimpan perubahan menggunakan `git add` dan `git commit`.

11. Hasil pengujian: berhasil.
