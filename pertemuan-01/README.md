Bukti Belajar P1
Fungsi: dokumentasi capaian pembelajaran P1
1. Konsep Dasar Pemrograman Web
pemrograman web adalah cara untuk membuat dan mengembangkan sebuah website. Dalam membuat website, HTML digunakan untuk membuat struktur, CSS untuk mengatur tampilan agar lebih menarik, dan JavaScript untuk membuat website bisa berinteraksi dengan pengguna. Selain itu, ada server dan database yang membantu menyimpan serta mengolah data. Jadi, semua bagian tersebut saling bekerja sama supaya sebuah website dapat berjalan dengan baik.

2. Arsitektur Klien-Peladen
Menurut yang aku pahami, klien-peladen (client-server) adalah sistem di mana klien meminta layanan atau data, sedangkan peladen/server menerima permintaan tersebut lalu mengolah dan memberikan hasilnya kepada klien. Contohnya, saat kita membuka website, browser sebagai klien meminta halaman kepada server, kemudian server mengirimkan halaman tersebut kembali ke browser.

3. HTTP Request dan Response
Menurut yang aku pahami, HTTP request dan response adalah proses komunikasi antara browser dan server. Request adalah permintaan yang dikirim oleh klien (browser) kepada server, sedangkan response adalah balasan dari server setelah menerima dan memproses permintaan tersebut. Contohnya, saat membuka sebuah website, browser mengirim request ke server, lalu server mengirim response berupa halaman website yang kemudian ditampilkan di browser.

4. HTML, CSS, JavaScript, PHP, 
Menurut yang aku pahami, HTML, CSS, JavaScript, dan PHP memiliki fungsi yang berbeda dalam membuat website. HTML digunakan untuk membuat struktur halaman, CSS untuk mengatur tampilan agar lebih menarik, JavaScript untuk membuat website lebih interaktif, sedangkan PHP digunakan untuk mengolah data dan menjalankan proses di sisi server. Keempatnya dapat digunakan bersama agar website dapat berjalan dengan baik dan memiliki fitur yang sesuai kebutuhan.

5. Hubungan Antarteknologi
Hubungan antar teknologi adalah keterkaitan, integrasi, dan pengaruh timbal balik antara satu jenis teknologi dengan teknologi lainnya untuk membentuk sebuah sistem yang lebih besar dan fungsional.
